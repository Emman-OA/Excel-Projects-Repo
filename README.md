📊 Data Technician Bootcamp - Excel Data Analysis Project
🚀 Project Overview

This project was completed as part of the Data Technician Bootcamp Week 1 Excel Workbook and demonstrates practical data analysis skills using Microsoft Excel. The workbook involved working with retail sales, bike sales, and product sales datasets to perform data cleaning, analysis, summarisation, and visualisation tasks.

Through a series of hands-on exercises, I applied Excel functions, PivotTables, charts, and data manipulation techniques to uncover insights from business datasets and improve data-driven decision-making skills.

🛠️ Skills Demonstrated
📐 Excel Formulas & Functions

Utilised a variety of Excel functions to analyse and manipulate data, including:

➕ SUM() - Calculate total sales and commission values
📊 AVERAGE() - Find average performance metrics
🎯 SUMIF() - Sum values based on specific criteria
📈 AVERAGEIF() - Calculate conditional averages
📅 DATE() - Create and manipulate date values
🗓️ MONTH() - Extract month information from dates
📆 YEAR() - Extract year information from dates
🔍 VLOOKUP() - Retrieve data from related tables
🆕 UNIQUE() - Generate lists of distinct values
🔄 SWITCH() - Categorise data based on predefined conditions and sales thresholds
